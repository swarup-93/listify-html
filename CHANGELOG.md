# Changelog

All notable changes to **Listify HTML** are documented here.

---

## [1.0.0] — Initial Release

### Added

* Generate list from selected text (HTML and Markdown)
* Support for `<ul>` and `<ol>` with `<li>` elements
* Auto detect list type (ordered / unordered)
* Smart cleaning of numbers and bullets in auto mode
* Manual mode preserves original text
* Nested list support based on indentation
* Support for newline and comma-separated input
* Reverse HTML list back to plain text
* Editor indentation support (tabs/spaces)
* Basic error handling and user messages
